Quick start

  1. Save the gateway admin password with Remember checked.
  2. Click Test gateway and Run check to confirm the Docker host can reach everything.
  3. Leave Dry run on while testing; reboot requests are logged but not sent.
  4. When both tests pass, turn Dry run off and save settings.
